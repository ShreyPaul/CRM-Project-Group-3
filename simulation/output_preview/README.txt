CRM project charts (en)
Five figures: composition, exceedance, individual sensitivities, B/C break-even,
and event frequency versus severity. Currency: USD millions.
Figures 1, 4, 5 use analytical means; 2, 3 use 20,000 simulated years.
Figure 4 compares means only, not P95. All other inputs remain fixed.
Run from the project root: cd simulation && uv run --frozen python make_chart.py
Run from the extracted bundle: cd scripts && uv run --frozen python make_chart.py
Requires NumPy and Matplotlib. Font: DejaVu Sans.
